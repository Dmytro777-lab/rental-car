# Rental Car

Учебный проект для поиска автомобилей и отправки заявки на аренду. Пользователь может отфильтровать каталог, посмотреть информацию об автомобиле и заполнить форму бронирования.

## Возможности

- Главная страница с переходом в каталог.
- Фильтрация автомобилей по марке, максимальной цене за час и пробегу от/до.
- Применение фильтров кнопкой **Search** и сброс кнопкой **Clear filters**.
- Загрузка по 12 автомобилей. Кнопка **Load more** добавляет следующую страницу с учётом выбранных фильтров.
- Открытие подробностей автомобиля в новой вкладке через **Read more**.
- Просмотр фотографии, цены, описания, характеристик, условий аренды и комплектации.
- Форма бронирования с проверкой имени, email и комментария.
- Отправка заявки в API, сообщение об успехе и очистка формы после закрытия сообщения.
- Блокировка кнопки Send во время отправки. При ошибке введённые данные сохраняются.
- Сообщения о загрузке, ошибках и отсутствии результатов.

Фильтрация и пагинация выполняются на сервере. Форма отправляет заявку на аренду, а не проводит оплату.

## Технологии

- Next.js App Router и React — страницы и компоненты.
- TypeScript — типизация данных.
- TanStack Query — загрузка данных и пагинация.
- Axios — запросы к API.
- Formik — форма бронирования и проверка полей.
- CSS Modules — стили компонентов.
- React Icons — иконки.

## Запуск локально

Проект проверен на Node.js 24. Для запуска нужны Node.js и npm.

```bash
git clone https://github.com/Dmytro777-lab/rental-car.git
cd rental-car
npm ci
npm run dev
```

Откройте [localhost:3000](http://localhost:3000). Если порт занят, используйте адрес из терминала.

Адрес API уже указан в `lib/api/cars.ts`; файл `.env` для текущей версии не требуется. Для загрузки данных, фотографий и шрифта Google Fonts нужен интернет.

## Страницы и файлы

- `app/page.tsx` — главная страница `/`.
- `app/catalog/page.tsx` — каталог `/catalog`.
- `app/catalog/[id]/page.tsx` — подробности автомобиля `/catalog/[id]`.
- `components/Catalog/` — список автомобилей и Load more.
- `components/CarFilters/` — форма фильтров на `useState`.
- `components/CarCard/` — карточка автомобиля.
- `components/CarDetails/` — подробная информация об автомобиле.
- `components/BookingForm/` — форма заявки на аренду.
- `components/Header/` — шапка и навигация.
- `components/QueryProvider/` — подключение TanStack Query.
- `lib/api/cars.ts` — функции запросов к API.
- `types/car.ts` — типы автомобилей, фильтров и заявок.

## Проверка вручную

1. Выбрать фильтры, нажать Search и проверить результаты.
2. Нажать Load more: новые автомобили должны добавиться к списку с теми же фильтрами.
3. Нажать Clear filters: поля должны очиститься, каталог — вернуться к первой странице.
4. Проверить сообщение No cars found для поиска без результатов.
5. Открыть автомобиль и проверить ошибки пустых полей, неверного email и цифр в имени.
6. Отправить корректно заполненную форму в учебный API: после подтверждения и закрытия сообщения поля должны очиститься.
7. Проверить обработку ошибки сети и сохранение введённых данных формы.
